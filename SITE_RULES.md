# Правила Public Website «Ваш Финдир»

## Граница

Публичные страницы рендерятся Symfony/Twig. Страница задаёт состав секций и контент, секция задаёт структуру, компонент отвечает за повторяемый элемент. Twig не делает запросов к базе и не содержит бизнес-правил. Опубликованные тексты, URL, SEO и форма заявки сохраняют свои контракты.

## Tailwind

Tailwind CSS 4.3.3 собирается командой `make assets` и не загружается в браузере как runtime. Единственный исходный файл — `site/assets/styles/website/app.css`; в нём допускаются только импорт Tailwind и директивы `@source` для Twig, JavaScript и Markdown рендерера. Результат сборки — `site/public/assets/website/app.css`. Административные Twig шаблоны до появления React Admin используют эту же сборку.

Для оформления использовать только стандартные классы Tailwind с палитрой, шрифтами, размерами и состояниями по умолчанию. В исходниках не добавлять к импорту и путям поиска другие CSS директивы или правила. В шаблонах не использовать inline оформление и произвольные значения в квадратных скобках. Не добавлять JavaScript, который задаёт CSS свойства. Классы, меняющиеся из JavaScript, должны присутствовать в исходниках, которые сканирует Tailwind.

До внедрения новой дизайн-системы страницы наследуют `website/layouts/page.html.twig` и содержат минимальную разметку без оформления; иконки остаются только в футере. Компоненты и секции в `site/templates/website/` переиспользуют существующие Twig partials. Не копировать их разметку между страницами. Состояния форм и кнопок выражать полными строками стандартных классов; не конструировать имя класса из переменной цвета. Для тёмной области явно указывать её классы в Twig.

## Поведение и доступность

Форма заявки отправляет `POST /lead` с CSRF и сохраняет существующие поля и `data-vf-*` hooks. Анонимный GET не начинает session без необходимости. Уведомление о cookie сохраняет выбор; мобильное меню доступно с клавиатуры. Не менять публичные URL без redirect. На странице один H1, форма имеет видимые labels и текст ошибок, интерактивные элементы имеют видимый focus. Уважать `prefers-reduced-motion`. Проверять отсутствие горизонтальной прокрутки на ширинах 320, 375, 768, 1024 и 1440px.

Layout централизованно выводит title, description, robots, canonical, Open Graph, Twitter и JSON-LD.

## Проверка

После изменения Twig, JavaScript или Tailwind entrypoint выполнить `make assets`, перенести значение `make asset-version` в оба layout и запустить `make assets-check` и `make ci`. Проверить основные публичные страницы, блог, форму заявки, cookie, мобильное меню, страницы ошибок и временный Twig Admin в браузере.
