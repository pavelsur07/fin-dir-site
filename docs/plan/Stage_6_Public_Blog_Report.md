# Stage 6 — Публичный блог «Газета»: отчёт

## Что реализовано

- `/gazeta` — список опубликованных статей из базы: по 12 на страницу, пагинация «← Новее / Раньше →», свой canonical у каждой страницы, честный empty state.
- `/gazeta/{slug}` — страница статьи:
  - хлебные крошки, H1, анонс, строка «дата · Редакция Ваш Финдир»;
  - оглавление по h2 (показывается, если разделов больше одного);
  - тело статьи из Markdown;
  - «Читайте также», если есть 2–4 другие статьи;
  - CTA на Telegram.
- SEO статьи:
  - title и description берутся из meta-полей, если их нет — из заголовка и анонса;
  - canonical, `og:type=article`;
  - JSON-LD `BlogPosting` + `BreadcrumbList`.
- Черновик, архив и неизвестный slug одинаково отдают 404 и неразличимы снаружи.
- `/gazeta/post-1` → **301** на `/gazeta/marketpleys-ili-internet-magazin`.
- Старая статья перенесена data-миграцией, только текст, в Markdown. Удалены:
  - фейковые просмотры и «dashboard»;
  - битые рубрики и кнопки «Поделиться»;
  - заглушки «Похожие» и картинки со стороннего CDN;
  - форма, которая теряла заявки: вместо неё CTA на Telegram.
- Попутно исправлена опечатка «бранд» → «бренд».
- `/sitemap.xml` генерируется: статические страницы и опубликованные статьи с `lastmod`. Статический файл удалён.
- Кеш: `Cache-Control: public, max-age=300`, сессия не стартует.
- Админка:
  - предпросмотр использует тот же рендер, что и сайт;
  - у опубликованных статей есть ссылка «Открыть на сайте».

## Решения

- **Чтение.** Отдельные публичные Query (`PublicPostListQuery`, `PublicPostQuery`, `PublicPostSitemapQuery`), каждый фильтрует по `PUBLISHED`. Админские Query не переиспользуются (PATTERNS §9).
- **JSON-LD.** Схему собирает `PostStructuredData` — чистая функция в PHP, как требует SITE_RULES §15.2 для динамического контента.
- **Markdown** (`MarkdownRenderer::renderArticle`):
  - id у h2 и h3, оглавление по AST;
  - `#` в тексте понижается до h2, чтобы H1 на странице был один;
  - таблица оборачивается в прокручиваемый контейнер;
  - картинки не выводятся, остаётся alt;
  - внешние ссылки получают `rel="noopener noreferrer"`.
- **Новые UI-паттерны** оформлены по SITE_RULES §13, в `SITE_RULES.md` и `/ui-kit` обновлено:
  - Grid: необязательные `item.href` (заголовок-ссылка вместо повторяющихся «Читать»), `item.meta` / `meta_datetime`, `pagination`;
  - роли Article List и Article;
  - компонент Pagination;
  - HTML из Markdown выводится в семантическом контейнере статьи;
  - у секции Article есть `heading_level: 'h2'` для страниц, где H1 уже есть (UI-kit).
- **Контроллер статьи** вызывает две Query и Markdown-адаптер. Это отступление от правила «один Query» (PATTERNS §6), но отдельный агрегирующий Query ради одной страницы был бы лишним.
- **Навигация блога** вынесена в `pages/_blog_navigation.html.twig`. CTA в шапке ведёт на `/#lead-form` — раньше на страницах блога была битая ссылка `#lead-form`.
- **Старый маршрут** `/gazeta/post-1` объявлен в `routes.yaml` раньше `/gazeta/{slug}`: иначе `post-1` разобрался бы как slug и дал 404.

## Ревью

- **Self-review:** найдено переполнение на 320px (исправлено) и замечание про 304 (решено вместе с ревью).
- **Claude Code review:**
  - **high:** хранимый XSS. Компонент `_json_ld` кодировал JSON без `JSON_HEX_TAG`, и заголовок статьи с `</script>` из админки выполнил бы скрипт на публичной странице. Сначала добавлен воспроизводящий тест, затем исправление `JSON_HEX_TAG|JSON_HEX_AMP`. Тест проверяет и защиту, и то, что JSON по-прежнему декодируется;
  - **medium:** 304 по `updatedAt` статьи отдавал бы устаревший HTML (блок «Читайте также», версия ассетов) → `Last-Modified` убран, остаётся `max-age=300`;
  - **medium:** если в админке уже создана статья со slug `marketpleys-ili-internet-magazin`, миграция молча пропустит импорт → действие перед релизом ниже;
  - **low, исправлены:** картинки и `rel` в Markdown, `@variant md`, `<article>`, тесты пагинации;
  - **повторное ревью:** blocker, high и medium нет. Low исправлены: проверка декодирования JSON-LD, `www.vashfindir.ru` во внутренних хостах.
- **Не исправлялось, принято осознанно:**
  - нет `image` в BlogPosting (картинок пока нет);
  - одинаковый description у страниц пагинации;
  - нет `lastmod` у `/gazeta` в sitemap;
  - разные коды ответа для `page=abc` (400) и `page=0` (404) — зафиксировано тестом;
  - после снятия с публикации статья до 5 минут может отдаваться из браузерного кеша (`max-age=300`).
