## 3. Что сделать

Общее для всех секций:
- **Заголовки секций (h2):** в макете `clamp(32px, 3.6vw, 52px)`, weight 700. На сайте сейчас `type-t2-article md:type-t2` (36 px). Сделать `type-t2 lg:type-t1` (48 px) — ближайший токен.

- **Контейнер:** оставить `max-w-container` сайта (1200 px). В макете 1280 px, но шапка и подвал сайта выровнены по 1200 — это осознанное отличие, в отчёте не считать ошибкой.
- **Кнопки внутри цветных карточек:** белая сплошная кнопка со стрелкой → (Lucide `arrow-right`), а не контурная. Для этого добавить в `components/_button.html.twig` вариант `inverse`: `bg-white text-accent hover:bg-cobalt-50` и полными строками классов `dark:` для тёмного фона.

## 4. Ограничения

- `SITE_RULES.md` и `AGENTS.md`: только классы темы и токены `vf-palette.css`, без `style=""` и значений в `[..]`, без JS, который задаёт CSS-свойства. Классы, которые переключает JS, должны быть в исходниках.
- Где макетного значения нет в шкале темы, брать ближайшее. Новые CSS-правила и токены не добавлять, кроме случая, когда без токена нельзя: тогда добавить его в `vf-palette.css` и указать в PR.
- `sections/_faq.html.twig`, варианты `default` и `panel` формы, страницы кроме главной — не менять.
- Прежние секции главной не удалять.
