# Stage 10 — `/ui-kit` по макету Design System: отчёт

## Результат

`website/pages/ui_kit.html.twig` заменён на каталог с тёмной вводной областью, логотипами, нумерованными разделами, шкалами Ink/Crimson, статусами, темами, контрастом, типографикой, геометрией, образцами production components и секций, палитрой данных, пустым состоянием, движением и публикациями. Верстка использует существующий website layout, Tailwind 4.3.3 и единственный `app.css`. Для 22 свотчей добавлены селекторы, ссылающиеся на канонические токены, без HEX и inline CSS в Twig. URL, `noindex`, SEO layout, формы и данные не менялись. Макетные цены, функции кабинета и фотография исключены по правилам v2.

При проверке мобильного меню найден отсутствующий `lockPage()` в website JavaScript. Добавлена блокировка прокрутки за диалогом через события, согласованная с уже существующим `unlockPage()`. Обе навигации на странице теперь открываются и закрываются с корректным `aria-expanded` и возвратом фокуса.
