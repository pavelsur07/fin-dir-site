# Stage 8 — Админка: сайдбар и рабочая зона на всю ширину. Отчёт

## Что сделано

- **Меню перенесено в сайдбар слева** (240px, тёмный, sticky: не уезжает при прокрутке):
  - бренд, пункты «Панель», «Публикации», «Обращения»;
  - внизу имя пользователя и «Выйти».
  - Активный раздел подсвечен (`aria-current="page"`), в том числе на вложенных страницах: редактирование и предпросмотр статьи, карточка обращения.
- **Рабочая зона** занимает всю ширину справа от сайдбара:
  - таблицы и списки на всю ширину;
  - формы и карточки ограничены 960px для удобства чтения.
- **Мобильная версия (до 900px), без JavaScript:** сверху тёмная полоса «Ваш Финдир · Админка» и кнопка «Меню» со счётчиком; по тапу раскрывается то же меню (нативный `<details>`).
- **Счётчик новых обращений** у пункта «Обращения». Считаются только обращения со статусом «Новое», при нуле счётчик скрыт. Данные идут через фрагмент-контроллер `LeadCounterController` и `NewLeadCountQuery`: Twig в БД не ходит. Счётчик считается один раз на страницу.
- **Страница входа** — без меню, карточка по центру.
- **Меню задано одним массивом** в `admin/layout.html.twig`: новый раздел добавляется одной строкой.
- **Доступность:**
  - ссылка «К содержимому»;
  - счётчик озвучивается как «новых обращений: N» (визуально скрытый текст, а не `aria-label` на `span`);
  - кнопка на мобильном называется «Меню»;
  - на каждой ширине в дереве доступности одна копия меню.
