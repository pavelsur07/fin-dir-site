# Stage: первый экран главной «Финдир на аутсорсинге: предсказуемые финансы и рост прибыли»

## Цель

Обновить первый экран главной (`sections/_hero` на `pages/marketing/home.html.twig`) по макету:
новые надзаголовок, подзаголовок и кнопка, строка гарантии у кнопки, три цифры внутри первого экрана
и карточка онлайн сервиса у фото. H1 на проде уже совпадает с макетом, его не менять.

Риск: обычный. Только Twig, конфиг текстов и одна иконка. `POST /lead`, CSRF, окно записи, URL, SEO и кеш не меняются.

## Состав и поведение

1. **Надзаголовок** — обычный текст акцентного цвета, мелкий полужирный (как `label`, но без рамки-пилюли; добавь вариант или аргумент в `_hero`, старые вызовы не ломать).
2. **Подзаголовок** — аргумент `lead`. Аргумент `note` теперь подпись под кнопкой.
3. **Гарантия** — новый необязательный аргумент `guarantee` (строка). Иконка `shield-check` через `components/_icon.html.twig` (добавь иконку в компонент из `icons/shield-check.svg`), цвет акцентный, текст основной, начертание medium.
4. **Цифры** — новый необязательный аргумент `facts` в `_hero`: строка из 2–3 фактов под гарантией, разделители вертикальной линией.
   - Источник — существующий глобал `vf_trust_facts` (один источник цифр). Вывести: «230+ / доверили нам учёт и финансы» (число и дата из конфига, владелец обновит до 235+) и «11 лет / в финансах».
   - Третий факт «23,5% прибыли в среднем теряют компании» с подсказкой выводить **только** когда в конфиге задан источник (поле `source`). Без источника не выводить, плейсхолдеры «[N]», «[период]» на сайт не попадают.
   - Подсказка, если выводится: кнопка с пунктирным подчёркиванием, текст по фокусу и наведению, доступна с клавиатуры, `aria-describedby`.
   - Те же факты убрать из полосы доверия на главной, чтобы цифры не повторялись (окно записи `_lead_modal` продолжает брать `vf_trust_facts`, его не трогать).
5. **Карточка сервиса** — новый необязательный аргумент `service_card` (true/false), новый компонент `components/_service_glance.html.twig`.
   - Это живой HTML, не картинка. Демо-цифры; для скринридера `role="img"` и подпись «Пример экрана онлайн сервиса, демонстрационные данные».
   - Десктоп: плавающая белая карточка ~224 px с тенью, как карточка с именем, слева сверху от фото с нахлёстом, не перекрывает лицо и карточку с именем.
   - Планшет (md…lg): скрыта.
   - Мобильный: под фото на всю ширину карточки.
   - На главной включить (`service_card: true`). Вариант без карточки — просто `false`, выбор владельца после просмотра на стенде.
6. **Мобильный порядок**: надзаголовок, H1, подзаголовок, кнопка на всю ширину, подпись, гарантия, фото с карточкой имени, карточка сервиса, три цифры в одну строку (3 колонки, цифра крупнее подписи).
7. **H1** во всех ширинах укладывается в три строки по смыслу (как сейчас). На 375 и 768 допустимо уменьшить размер, чтобы «предсказуемые финансы» не переносилось.

## Критерии приёмки

- [ ] 1440×800: H1, кнопка, гарантия и цифры видны без прокрутки.
- [ ] 375×667: кнопка видна без прокрутки.
- [ ] Тексты совпадают с таблицей до знака; на сайте нет текста в квадратных скобках.
- [ ] Карточки не перекрывают лицо на 320, 375, 768, 1024, 1366, 1440; горизонтальной прокрутки нет.
- [ ] Один H1; фокус кнопки и подсказки виден; `prefers-reduced-motion` соблюдён (анимации карточек не обязательны, если есть — только появление).
- [ ] Анонимный GET главной не ставит `Set-Cookie`, ответ кешируемый (как сейчас).
- [ ] Существующие тесты главной и окна записи проходят; добавить проверки: на главной есть строка гарантии, кнопка с `data-vf-lead-modal-open`, нет «[N]» и «[период]».
