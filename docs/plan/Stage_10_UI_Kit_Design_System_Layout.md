# Stage 10 — верстка `/ui-kit` по `Design System.dc.html`

## Цель

Заменить состав и верстку `website/pages/ui_kit.html.twig` на технический каталог по визуальному эталону `design-system-inbox/Design System.dc.html`: тёмная вводная область, нумерованные блоки, плотная сетка образцов и светлая основная область шириной до 1200px. Страница остаётся на Symfony/Twig, Tailwind CSS 4.3.3, Inter/Manrope и v2 токенах. Сохранить `/ui-kit`, `noindex`, общую навигацию, footer и production-компоненты.

## Граница и адаптация эталона

Эталон — 29 крупных секций, 3206 строк, с inline CSS/JS, `sc-for`, React-примерами и маркетинговыми образцами. Его синтаксис не переносится в runtime. В страницу входят блоки основ системы (логотип, палитра, статусы, темы, контраст, типографика, радиусы, пространство, тени, иконки, состояния), палитра данных, пустое состояние, движение, образцы публикаций и действующих production components (формы, кнопки, уведомления, навигация), а также превью действующих секций сайта. Примеры цен, кабинета, неподтверждённой фотографии и операции, которых сайт не поддерживает, не публикуются. Из эталона также исключены генератор логотипа, подтверждение операций, карточки вымышленных сотрудников, форма кабинета и исходный `tailwind.config.js`: они не являются production-паттернами Public Website. Вместо фактов о компании и налогах в образцах статей используются явно технические тексты. Структура каталога и смысл блоков сохраняются, демо-данные остаются явно техническими.

## Шаги

1. Зафиксировать DOM-контракт тестом: вводный блок, нумерованные разделы, свотчи, обе темы, production components, отсутствие inline CSS/JS, один H1, noindex.
2. Обновить Twig page и необходимые showcase partials. Для палитры использовать канонические CSS-переменные через ограниченные стили каталога в единственном `app.css`; не дублировать HEX в Twig.
3. Проверить адаптивность 320/375/768/1024/1440px, доступность образцов и отсутствие горизонтального скролла. Обновить `SITE_RULES.md`, если появится новая категория каталожных стилей.
4. `make assets`, `make asset-version`, `make assets-check`, `make ci`, self-review, Claude Code review, отчёт. Не включать исходный дизайн-пакет в runtime.
