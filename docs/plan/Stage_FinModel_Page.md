## Цель

Заменить заглушку `/services/finansovaya-model-ot-professionala` (`service_financial_model`,
`pages/marketing/service_financial_model.html.twig`) полноценной страницей услуги по макету
и открыть её для индексации. URL, имя маршрута и контроллер не меняются.

Риск: обычный. Только Twig/секции/конфиг текстов и ассеты; схема БД, `POST /lead`, CSRF не меняются.
Деплой — штатный, после merge в master.

### Тексты

Брать из `FinModel.dc.html` дословно, кроме:

- H1: «Разработка финансовой модели бизнеса» (как сейчас — ключевой запрос; в макете без «бизнеса»).
- FAQ «Сколько времени занимает разработка?»: без «[Уточнить срок.]» — «Зависит от сложности бизнеса и того, насколько готовы данные учёта. Срок называем после первой встречи.»
- Подпись «Заглушки: подставить реальные кейсы…» и все тексты в квадратных скобках на сайт не попадают.

## SEO и индексация

- Убрать `{% block robots %}noindex, follow{% endblock %}`.
- Добавить `service_financial_model` в список `SitemapController`.
- `description` (≤ 160): «Финансовая модель бизнеса под ключ: прогноз прибыли и денег на 12 месяцев, ОПиУ, ДДС, баланс и сценарии. Разработка с финансовым директором.»
- `title` без изменений.
- JSON-LD как на странице финдира: `Service` (name, description, provider — организация, areaServed RU) и `FAQPage` из `vf_finmodel_faq`, через `components/_json_ld`.
- Пункт в шапке меню не добавлять (страница доступна со страницы «Услуги», как сейчас).
- Кеш `public, max-age=300` и отсутствие сессии сохранить.

## Тесты

- `tests/Website/FinancialModelServicePageTest.php`: страница больше не заглушка —
  убрать её из провайдера заглушек (`servicePages`), остальные заглушки (`service_accounting`, `service_financial_accounting`) не трогать.
  Новые проверки: 200, один H1 с текстом, нет `noindex`, canonical, есть секции «Из чего состоит», «Этапы работы», FAQ, форма `consultation`
  с CSRF, ссылка на `service_financial_director`, `Set-Cookie` отсутствует, ответ кешируемый, JSON-LD `Service` и `FAQPage`.
- Sitemap содержит URL страницы (заменить проверку «не в sitemap»).
- Меню шапки: проверка «нет в меню» остаётся.
- Существующие тесты главной, финдира и форм проходят без изменений.

Ручная проверка: 320/375/768/1024/1366/1440 без горизонтальной прокрутки; один H1; фокус виден;
кнопка hero открывает окно записи; форма отправляется (201) и попадает в админку; FAQ открывается с клавиатуры;
`prefers-reduced-motion`; изображения с `width/height`, ниже первого экрана — `loading="lazy"`.

## Открытые места (решает владелец, на запуск не влияют)

1. Число разработанных моделей для полосы доверия («[N]+ моделей»). Появится — добавить третий факт (только для этой страницы).
2. Сроки этапов. Появятся — заполнить аргумент шагов, строка «Срок» выведется сама.
3. Кейсы именно по финмоделям. Пока секция показывает свежие опубликованные кейсы; фильтр по услуге — отдельная задача.
