# Stage: JSON-LD FAQPage для статей «Газеты»

Статус: отложено. Разметка под неё уже есть, схема не формируется.

## Цель

Выводить в `<head>` статьи структурированные данные `FAQPage`, если в тексте есть раздел «частые вопросы» (или «FAQ»). Схема должна строиться из тех же вопросов и ответов, которые видит читатель.

## Что уже сделано

- `MarkdownRenderer` помечает каждый H3 внутри раздела «…частые вопросы» атрибутом `data-vf-faq="question"`.
- Ответ — все блоки после H3 до следующего заголовка.
- Раздел определяется по заголовку H2, содержащему «частые вопросы», либо равному «FAQ» (без учёта регистра).

## Что нужно сделать

1. Извлечь пары «вопрос — ответ» из AST в `MarkdownRenderer` и вернуть их в `RenderedArticle` (например, поле `faq`: список `{question, answer}`). Ответ — plain text без HTML.
2. Передать пары в `PostStructuredData::build()` и добавить третий элемент схемы `FAQPage` с `mainEntity` из `Question` и `acceptedAnswer`. Если пар нет — схему не добавлять.
3. `PostShowController` не должен сам разбирать Markdown; данные берутся из `RenderedArticle`.
4. Тесты:
   - Unit на извлечение пар: раздел есть, раздела нет, H3 вне раздела не попадают.
   - Unit на `PostStructuredData`: наличие и отсутствие `FAQPage`.
   - Functional: JSON-LD присутствует на странице статьи-образца `marketpleys-ili-internet-magazin` (4 вопроса).

## Открытые вопросы

- «Заглушка данных»: как решено, при отсутствии данных FAQ схема не выводится, а не подставляется пустая или фиктивная. Если нужна именно заглушка, уточнить её содержимое до начала работ.
- Нужна ли валидация в Google Rich Results Test перед релизом.

## Риск и проверки

Риск обычный: только представление и Adapter, без security и данных. Проверки: `make test`, `make phpstan`, `make lint`. Существующие схемы BlogPosting и BreadcrumbList не менять.
