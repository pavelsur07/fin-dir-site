Снимки сохранены в [ui-kit-audit](ui-kit-audit/): nav16-reference-WIDTH.png — эталон в исходном состоянии (панели «Возможности» и компании открыты); nav16-WIDTH-closed.png — закрытый образец; nav16-WIDTH-open.png — обе независимые панели открыты; nav16-WIDTH-PANEL.png — каждое из семи раскрытых состояний (features, audiences, mobile-features, mobile-audiences, company, user, crumbs). Сценарий запускается в среде с Playwright 1.62.1 и принимает BASE_URL проверяемого локального сайта.

На всех пяти ширинах: HTTP 200; один H1; нет ошибок JavaScript, ошибок загрузки website assets и горизонтальной прокрутки документа. Сценарий проверяет Enter, Space, Tab внутрь открытых панелей сайта и компании, Escape с возвратом фокуса, независимое открытие панелей, закрытие кликом снаружи и при уходе фокуса, поиск с пустым результатом, поиск ИНН без пробелов, сброс фильтра и выбор демонстрационной компании. Отдельное состояние touch на 375 px проверяет касание панелей и выбор компании. Состояние prefers-reduced-motion использует общее правило CSS, отключающее переходы.

## Решения при переносе

- Четыре подраздела 16.1–16.4 и их компоновка присутствуют в порядке эталона. Кнопки панелей имеют aria-controls, aria-expanded и hidden; соседние панели одной группы закрываются, независимые образцы открываются одновременно.
- Обычные цепочки крошек используют production partial; сокращённая цепочка остаётся техническим образцом с раскрываемыми ссылками. JSON-LD внутри образца использует явно демонстрационный домен example.test и не включается в SEO-разметку страницы.
- Цены, личные данные, фактические показатели и несуществующие действия кабинета заменены маркированными демонстрационными данными. Раздел 16 не создаёт реальный кабинет и не подменяет production Navbar.
- Эталон выводит дополнительный горизонтальный скролл документа на 320/375 px. В реализации он исправлен; широкие образцы прокручиваются только внутри собственных областей.
- Эталон загружает также Onest/Golos Text. Для /ui-kit сохранены только согласованные локальные Inter/Manrope.
- Примеры крошек и JSON-LD находятся только в техническом каталоге и не добавляются в SEO-разметку страницы.
- Production Navbar остаётся в каталоге /ui-kit/sections и на обычных страницах; раздел 16 демонстрирует расширенную структуру эталона.
- У нескольких независимых технических образцов есть собственный текущий пункт; их aria-current относится к образцу, а не к маршруту /ui-kit. Пагинация кабинета показана как статический макет без ложных ссылок.

Playwright-сценарий хранится в репозитории, но не запускается командой make ci: ему требуется отдельная среда с Chromium и пакетом playwright 1.62.1. PHP unit/functional checks включены в make ci; браузерный сценарий запущен отдельно по отчёту выше.

Итог проверки: make assets и make assets-check прошли; make ci — 225 тестов, 2624 утверждения. Smoke-проверка маршрутов /, /services, /ui-kit/sections и /ui-kit прошла. Независимое ревью через Claude Code проведено четырежды; блокирующих замечаний, а также high и medium после исправлений нет. Последнее ревью выявило мелкие случаи поиска, Escape после клика в Safari и имя кнопки крошек — исправлены и включены в повторный браузерный сценарий. Оставшийся нюанс технического образца: раскрытые средние звенья сокращённой цепочки находятся в одном пункте списка; при реальном использовании такой структуры каждое звено следует оформить отдельным пунктом.

Разделы 06–15 и 17–28 по-прежнему требуют отдельной сверки и исправления.
