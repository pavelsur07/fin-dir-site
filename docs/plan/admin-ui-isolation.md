# Изоляция и исправления Twig Admin

Задача: Admin имеет независимые CSS/JS, меню таблиц не обрезается и работает
с клавиатурой, интерфейс доступен на узком и низком экране. Public Website
сохраняет оформление, контент, маршруты и поведение. Security и данные не меняются.

Обычный риск: build-конфигурация и presentation layer нескольких модулей;
нужны полный CI-набор, отдельная проверка классов и браузерная проверка.

## Порядок реализации

1. Выделить общие неизменённые fonts/theme/palette в `styles/shared/`.
   Создать admin entrypoint и перенести скрипт вкладок в `scripts/admin/`.
   Разделить build/watch/check/version в Makefile и проверку классов в CI.
   Website source больше не сканирует Admin. Обновить устаревшие проверки,
   закреплявшие общую сборку, на контракт изоляции ресурсов.
2. Свести меню трёх таблиц в `_row_menu.html.twig`. Без JS — details в потоке;
   с поддержкой API — кнопка с popovertarget и auto popover. Позиционирование
   относительно кнопки с ограничением viewport, закрытие при прокрутке/resize.
   HTTP forms, CSRF и бизнес-действия сохраняются.
3. Центральная шкала слоёв: navigation 10, skip link 20, меню в top layer.
   Ограничить высоту мобильной навигации динамическим viewport.
4. Центрировать форму входа, ограничить её ширину, обеспечить интервалы,
   touch targets и focus полей. Исправить перенос длинного текста и отступы
   форм. Проверить вкладки и запасной вариант меню без JS.

## Правила и проверка

Правила: `ADMIN_RULES.md`, согласование границ в `AGENTS.md`, `SITE_RULES.md`,
актуальные пути shared foundations в `design-system-inbox/README.md`.

Проверки: `make assets`, независимые версии обоих bundles, `make ds-check`,
`make ci`, `make admin-browser-check`, self-review полного diff и
`git diff --check`. Browser fixtures рендерятся Symfony/KernelBrowser на
синтетических данных в тестовой БД и откатываются DAMA; проверка Chromium
не выполняет административные POST-действия.

## Результат проверки

Общие fonts/theme/palette перенесены без изменения содержимого; в публичном
layout изменён только хеш ресурсов. Бизнес-код, схема БД и security не менялись.

`make ci` прошёл: 360 тестов, 2729 assertions, PHPStan и Deptrac без ошибок.
После уточнения геометрии меню повторно прошли `make ds-check`, `make cs` и
весь `make test`. Визуальный self-review выявил слишком узкие столбцы на
мобильном экране; таблицы получили минимальную читаемую ширину и выборочный
перенос длинных текстовых ячеек. После этой правки прошли `make ds-check`, 104 теста Admin и связанных
сценариев (578 assertions), `make admin-browser-check` — 54 проверки страниц
и viewport. Проверены меню, клавиатура, возврат фокуса, внутренний scroll,
низкий экран, вкладки, отсутствие JS и отсутствие Popover API. Self-review
полного diff и `git diff --check` завершены. Browser checks выполнялись
Chromium, Safari/Firefox отдельно не проверялись.
