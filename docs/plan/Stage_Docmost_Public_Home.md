# Публичная главная Docmost

## Цель

По запросу пользователя открывать документацию без авторизации при переходе
на `https://docs.vashfindir.ru/`. Ранее согласованный production-релиз
продолжается через PR/CI и ручной deploy; повторное разрешение не требуется.

## Анализ и решение

В workspace найдена одна уже опубликованная пользователем страница:
«Документация сервиса Ваш Финдир», share `hn9f97nx4m`, slug `vaIvbFr1b5`.
Анонимный `/api/shares/page-info` подтвердил её доступность. Настройки
публикации и содержимое не изменяются, другие страницы не раскрываются.

Добавить к меткам Docmost приоритетный роутер только для `Host` и `Path(/)`.
Он отвечает временным `302` на существующую публичную страницу. Редактор
остаётся на `/login` и `/home`, API и shared pages идут в прежний backend.
Менять Symfony, общий Traefik или добавлять proxy/frontend не требуется.

## Риск и проверки

Риск высокий: production routing и граница публичного/закрытого контента.
Обязательны self-review и независимое read-only ревью всего изменения.

1. Проверить Compose и выполнить `make docmost-smoke`: настоящий временный
   Traefik должен перенаправлять только `/` (включая query string), оставлять
   `/login`, `/home`, API и share routes в backend и не перехватывать иной host.
2. Пройти CI, слить PR и выполнить ручной deploy без повторного bootstrap.
3. Снаружи проверить `302` корня, чтение целевой страницы анонимно, доступность
   редакторского входа, `401` закрытого API и health соседних сайтов.

Переход временный, чтобы браузеры не сохраняли навсегда выбранную главную.
При отмене sharing пользователем публичная страница перестанет открываться;
для замены главной нужно обновить URL в метке `redirectregex.replacement`.
Применение новых labels пересоздаёт только Docmost и может кратко прервать
его обслуживание; база и файлы сохраняются в существующих volumes.

## Локальная проверка

`make docmost-smoke` подтвердил настоящий `302` на выбранную публичную страницу,
passthrough входа/API/share, изоляцию host, авторизацию, сохранение данных при
пересоздании контейнеров и backup. `git diff --check` пройден. Независимое
read-only ревью полного изменения завершено без существенных замечаний.
