# Макеты страниц услуг

Макеты из дизайн-холста «Ваш Финдир — посадочная страница». Только референс: в работу
берутся отдельной задачей, в этой ветке не реализуются.

| Макет | Скриншот | Текущая страница сайта |
|---|---|---|
| `FinModel.dc.html` / `FinModelMobile.dc.html` | `finmodel-desktop.jpg`, `finmodel-mobile.jpg` | `/services/finansovaya-model-ot-professionala` (`service_financial_model`) |
| `CFO.dc.html` / `CFOMobile.dc.html` | `cfo-desktop.jpg`, `cfo-mobile.jpg` | `/services/finansovyy-direktor-na-autsorsinge` (`service_financial_director`) |

`*.dc.html` ссылаются на изображения холста (`/_blob/…`) и вне холста без картинок;
внешний вид смотреть по `*.jpg`. Тексты и структура — в `*.dc.html`.

Открытые места в макетах (заполнить до вёрстки):

- «Финансовая модель»: число построенных моделей ([N]+), сроки этапов, кейсы, график сценариев — заглушки.
- «Финдир на аутсорсинге»: кейсы (на сайте берутся из админки), формулировки таблицы сравнения — проверить.
