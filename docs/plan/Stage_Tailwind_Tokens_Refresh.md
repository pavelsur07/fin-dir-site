# Обновление токенов Tailwind и выпуск

## Цель

Подключить согласованные navy/red/paper токены и локальные шрифты в Public Website,
привести кнопки, заголовки и метрики к новой типографике, затем выпустить через
существующий GitHub Actions deploy workflow.

## Границы и риск

Риск высокий из-за изменений общей темы сайта и временного Twig Admin.
Существующий `vf-theme.css` остаётся нетронутым; одни и те же имена токенов
переопределяются в `app.css`. Не менять бизнес-логику, схему БД, production
конфигурацию и соседние сайты. Для новых шрифтов добавить локальные WOFF2 и
лицензии. Красный использовать у основных CTA, вторичные кнопки — navy.

## Приёмка и проверки

1. `make assets`, версия assets в обоих layout, `make assets-check`, `make ds-check`.
2. `make ci`, просмотр полного diff и независимое ревью согласно `AGENTS.md`.
3. Проверка контраста текста, классов и шрифтов; основные публичные страницы,
   форма, cookie, мобильное меню и временный Admin в браузере на 320–1440 px.
4. PR в `master`, обязательный CI, merge. Push в `master` запускает deploy;
   дождаться успешного workflow и проверить публичный HTTP/health.

Откат при подтверждённом дефекте — отдельный revert коммита релиза с повторным
прохождением CI и деплоя. Миграций нет.
