# Forty-Two Years of Inference Silicon

An interactive research report: 1985–2026 rebuilt as six windows, and the question of whether the
2023–2026 inference boom is a rerun of an old cycle or a new one under new constraints. A
four-state animated cover, twenty-odd signature charts, a persistent right-rail dashboard, and
every number on the page clickable back to a dated source.

No build step — open `index.html` directly, or serve the folder from any static server:

```bash
python3 -m http.server 8531
```

[info.md](info.md) is the delivery guide: what to ask the user, how the page is put together, and
how to re-theme the whole thing for a different industry.
